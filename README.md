# 🍕 Pizza Sales Analysis using SQL and Power BI

## 📌 Project Overview
This project analyzes pizza sales data using MySQL and Power BI to understand sales performance, revenue trends, customer ordering patterns, and product performance.

The dashboard provides interactive visualizations to identify popular pizza categories, preferred pizza sizes, busiest days, and monthly sales trends.

## 🎯 Project Objectives
- Analyze total revenue and sales performance.
- Calculate total orders and pizzas sold.
- Identify the best-selling and worst-selling pizzas.
- Analyze daily and monthly order trends.
- Compare sales by pizza category and pizza size.
- Identify peak ordering days and hours.
